# Registro de innovación semanal — Sales Management Grupo 2

## S10 · Administración de cuentas clave II · 21/10/2026

- **Lo trabajado en S9:** administración de cuentas clave I; selección/priorización de cuentas, actores y propuesta de valor, con presentación ejecutiva. S10 toma esos productos como punto de partida, no los vuelve a presentar como diapositivas.
- **Diseño de S10:** guía explicativa impartible. La página enseña primero qué es la gestión de cuentas clave, cómo se organiza un plan, cómo se desarrollan relaciones y cómo se coordina internamente; después incluye práctica guiada, sprint de 90 días, feria de planes y cierre.
- **Secuencia didáctica:** recuperación de S9 → explicación con ejemplos → práctica guiada con el caso ficticio Clínica Horizonte → plan de cuenta a 90 días → TP2 oficial independiente → feria de planes → quiz de aplicación y compromiso de salida.
- **Mecánicas de aprendizaje:** decisión ramificada con retroalimentación conceptual, conversación en parejas para reconocer actores, selección de acciones en una secuencia 30/60/90 y feria con recomendación accionable. Estas dinámicas apoyan la explicación, no la reemplazan. Evitar repetir automáticamente en la próxima sesión el mismo caso y sprint.
- **Validación elegida por el docente:** quiz formativo de 10 preguntas/10 puntos. Se probó el flujo y muestra el resultado (p. ej., 10/10), explicaciones por respuesta y opción de volver a intentarlo. No guarda datos personales ni afecta el libro de notas o el TP2 oficial de 30 puntos.
- **Control para impartir la clase:** el HTML incluye «Presentar clase», avanzar/retroceder, contador y barra de progreso, reiniciar desde el inicio y salir; el reinicio limpia las decisiones y selecciones de las dinámicas. Se admite teclado: flechas, Page Up/Down, Inicio/Fin y Esc.
- **QA en la página publicada:** despliegue de GitHub Pages completado con éxito. Se probaron inicio, anterior/siguiente, contador (15 tramos), teclado (flecha derecha, Inicio, Fin y Esc), retroalimentación de la práctica, secuencia del plan 3/3 y reinicio: volvió al primer tramo, limpió selecciones y respuestas. UAM Virtual conserva la URL original del recurso y ahora muestra el nombre “Guía de clase S10”; el plan semanal y el resumen coinciden con la nueva ruta de 159 minutos. Quiz y TP2 permanecen separados.
- **Adaptabilidad:** el HTML incluye reglas para 760 px y 400 px, y la estructura usa columnas que se apilan. Se intentó forzar una ventana de 375 px en el navegador de pruebas, pero este mantuvo 1280 px; por eso no se afirma una comprobación visual real a ancho móvil.
- **Cuidado de evaluación:** cuando el docente solicite un quiz, dejar visible el puntaje al completar. No asignar peso oficial ni editar calificaciones sin aprobación específica; si el quiz es un HTML externo, aclarar que el puntaje es visible localmente y no se registra en el libro de Moodle.
- **Próxima sesión:** elegir otra identidad y estructura basadas en el contenido del syllabus; consultar primero modalidades de evaluación disponibles y no volver a una presentación tipo diapositivas interactiva como formato por defecto.
